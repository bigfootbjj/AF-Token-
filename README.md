# AF Token

Experimental ERC-20 token on Polygon testing coordination around tiny liquidity and deflationary mechanics.

## What is AF?

AF is a live on-chain experiment, not a traditional crypto project with promises or roadmap hype. The core idea is simple: test whether a widely distributed, low-value token with very small liquidity can still attract a community of patient holders who understand the coordination game.

If holders hold and avoid dumping into a fragile pool for negligible amounts, the market can remain stable and slowly grow over time. If they rush to sell, the price collapses and the experiment highlights how difficult real coordination can be.

- 1% burn on every transfer, making the supply permanently deflationary
- Large portion reserved for automated on-chain distribution (gas refund bot)
- Small liquidity pool (AF/USDC) on Polygon DEX
- Transparent treasury, all movements auditable on-chain

## Distribution

AF uses an automated gas refund bot that sends a small fixed amount (currently 2 AF) to new Polygon users when they make their first ever transaction on the network.

Eligibility:
- First transaction ever on Polygon
- Gas cost between defined range (filters spam)
- One wallet = one bonus, forever (no farming)

All distributions are visible in real-time on PolygonScan.
